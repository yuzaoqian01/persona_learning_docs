## ClientS

viem中有三种类型的**客户：**

- 提供对[公共操作](https://viem.sh/docs/actions/public/introduction)（例如和）访问权限的[公共客户](https://viem.sh/docs/clients/public)端。`getBlockNumber``getBalance`  publicClient 对应的以太坊的provider
- 钱包[客户端](https://viem.sh/docs/clients/wallet)，提供对[钱包操作的](https://viem.sh/docs/actions/wallet/introduction)访问权限，例如`sendTransaction`和`signMessage`。 WalletClient 对应以太坊的singer
- [测试客户端](https://viem.sh/docs/clients/test)，提供对[测试操作的](https://viem.sh/docs/actions/test/introduction)访问权限，例如`mine`和`impersonate`。

## Transports (连接器？)

A **Client** is instantiated with a **Transport**, which is the intermediary layer that is responsible for executing outgoing requests (ie. RPC requests).

There are three types of Transports in viem:

- A [HTTP Transport](https://viem.sh/docs/clients/transports/http) that executes requests via a HTTP JSON-RPC API.
- A [WebSocket Transport](https://viem.sh/docs/clients/transports/websocket) that executes requests via a WebSocket JSON-RPC API.
- A [Custom Transport](https://viem.sh/docs/clients/transports/custom) that executes requests via an [EIP-1193 `request` function](https://eips.ethereum.org/EIPS/eip-1193).

客户**端**通过**传输层**进行实例化，传输层是负责执行传出请求（即 RPC 请求）的中间层。

viem中有三种类型的运输方式：

- 通过 HTTP JSON-RPC API 执行请求的[HTTP 传输协议](https://viem.sh/docs/clients/transports/http)。
- 通过 WebSocket JSON-RPC API 执行请求的WebSocket[传输。](https://viem.sh/docs/clients/transports/websocket)
- [通过EIP-1193](https://eips.ethereum.org/EIPS/eip-1193)[功能](https://eips.ethereum.org/EIPS/eip-1193)执行请求的[自定义](https://viem.sh/docs/clients/transports/custom)传输。[`request`](https://eips.ethereum.org/EIPS/eip-1193)

```js
// 公共客户端
const publicClient = createPublicClient({
  ccipRead: true, //CCIP 读取默认启用，但如果设置为false，客户端将不支持链下 CCIP 查询
  ccipRead: {
    async request({ data, sender, urls}){
      
    } //用于发起链下CCIP查询请求的函数
  },
  experimental_blockTag: 'pending', // 用于操作的默认块标签
  batch: {
    multicall: false,  // 批量多调用 默认false
    batchSize:1_24, //每个多调用（）调用数据块的最大大小（以字节为单位)某些 RPC 提供商会限制单个请求中可发送的调用数据量
    deployless: false, //启用无需部署的多路调用
    wait: 0, //发送一批数据前等待的最大毫秒数。
    cacheTime: 10_000,// 缓存数据在内存中保留的时间（以毫秒为单位）。
  },
  key: 'public',// 客户端标识
  name: 'Public Client',// 客户端名称
  pollingInterval:4_000,//轮询操作的频率 （毫秒单位）
  chain: mainnet, // 网络
  transport: http(), // 连接器
  rpcSchema: rpcSchema<CustomRpcSchema>(), //客户端的类型化JSON-RPC架构
})
```

```js
import { createPublicClient, createWalletClient, http, custom } from 'viem'
import { arbitrum } from 'viem/chains'

// 公共客户端
const publicClient = createPublicClient({ 
  chain: arbitrum, 
  transport: http(), 
}) 


// 钱包客户端
const walletClient = createWalletClient({
  chain: arbitrum,
  transport: custom(window.ethereum!)
})


export { publicClient, walletClient }
```

## Local Accounts (Private Key, Mnemonic, etc)

A Local Account performs signing of transactions & messages with a private key **before** executing a method over JSON-RPC.

There are three types of Local Accounts in viem:

- [Private Key Account](https://viem.sh/docs/accounts/local/privateKeyToAccount)
- [Mnemonic Account](https://viem.sh/docs/accounts/local/mnemonicToAccount)
- [Hierarchical Deterministic (HD) Account](https://viem.sh/docs/accounts/local/hdKeyToAccount)
