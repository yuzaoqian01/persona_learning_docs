## 1️⃣ 页面结构与布局

### 1.1 基本布局

- `html, body` 高度 100%，禁止 window 滚动：

```css
html, body {
  height: 100%;
  overflow: hidden; /* 防止 iOS 弹性空白 */
}
```

- 内容包裹在滚动容器内：

```css
.scroll-container {
  height: 100%;
  overflow-y: auto;
  -webkit-overflow-scrolling: touch; /* iOS 弹性滚动 */
}
```

- 统一使用 **flexbox 或 grid** 布局，保证兼容不同屏幕尺寸。

### 1.2 响应式

- viewport 设置：

```css
<meta name="viewport" content="width=device-width, initial-scale=1, maximum-scale=1, user-scalable=no">
```

- 适配方案：
  - rem 方案（以 100vw / 10 = 1rem）
  - media query 针对特殊屏幕
  - 高分屏图片处理：2x / 3x

### 1.3 容器滚动 vs window 滚动

- **推荐**：容器滚动（解决 iOS WebView 弹性空白）
- 避免直接操作 `window.scroll` 高频事件

## 2️⃣ 滚动与交互

### 2.1 上拉 / 下拉处理

- 下拉刷新：容器 scrollTop 判断或 IntersectionObserver
- 上拉加载：尾部观察器 + load more
- 避免多次触发状态冲突，统一管理 `loading` / `done` / `error`

### 2.2 点击与触摸事件

- 避免 300ms 点击延迟（现代浏览器自动优化）
- touchstart + preventDefault 可用于特殊组件
- 阻止滚动穿透：modal、drawer、picker 等组件需禁用背景滚动

### 2.3 弹性滚动处理

- iOS 使用 `-webkit-overflow-scrolling: touch`
- 安卓低版本可用第三方滚动库（BetterScroll / iScroll）

- 尽量避免 `window.onscroll` 高频操作
- 使用容器滚动或 `IntersectionObserver` 监听触底加载：

```ts
const observer = new IntersectionObserver((entries) => {
  entries.forEach(entry => {
    if (entry.isIntersecting) loadMore();
  });
});
observer.observe(document.querySelector('#loadMoreTrigger'));
```

- 下拉刷新可通过容器滚动 + 逻辑判断实现。

## 3️⃣ 视觉与动画

- 优先使用 GPU 加速属性：`transform`, `opacity`
- 避免 `top/left` 动画
- 复杂动画可使用 requestAnimationFrame
- 避免同时操作大量 DOM，使用虚拟 DOM 或 Canvas 渲染
- 过渡与动画需考虑低端机性能

## 4️⃣ 性能优化

### 4.1 首屏优化

- 内联关键 CSS / JS
- 骨架屏代替白屏
- 图片 lazy-load

### 4.2 JS 性能

- 节流 / 防抖
- 避免频繁 DOM 操作
- 减少不必要的 setState / rerender

### 4.3 列表性能

- 使用虚拟列表或分页
- 避免大列表直接渲染 DOM
- react-virtualized / vue-virtual-scroll-list

### 4.4 打包优化

- Tree shaking / code splitting
- 按需加载组件
- 压缩 JS / CSS / 图片

```css
<meta name="viewport" content="width=device-width, initial-scale=1, maximum-scale=1">
```

```css
// 新增 viweport-fit 属性，使得页面内容完全覆盖整个窗口

```



### ✔ 标准 2：使用 rem（750 设计稿）

- `html { font-size: calc(100vw / 7.5); }`
- 对应字节 / 阿里常用

### ✔ 标准 3：禁用全局 scroll（防 iOS 回弹）

大厂 90% 的移动页面都这么写：

```css
html, body {
  height: 100%;
  overflow: hidden;
}
```

→ 页面滚动交给内容容器（scroll-container）

# 2. 滚动标准

### ✔ 标准 4：使用“内部滚动容器 + 禁止 body 滚动”

阿里、字节、腾讯确实都是这样：

```css
html, body {
  height: 100%;
  overflow: hidden;
}

.scroll-container {
  height: 100%;
  overflow-y: auto;
  -webkit-overflow-scrolling: touch;
}
```

为什么？

- iOS 不再出现 Rubber Band 回弹（白屏、位移）
- webview 内滚动不会带动外层
- 更精准控制“吸顶、下拉加载、上拉滚动”

### ✔ 标准 5：滚动优化

```
.scroll-container {
  overscroll-behavior: contain;
}
```

### ✔ 标准 6：禁用双指缩放

```
<meta name="viewport"
      content="width=device-width, initial-scale=1, maximum-scale=1, user-scalable=no" />
```

# ✅ 3. Touch 事件标准

### ✔ Standard 7：禁用 iOS 300ms 点击延迟

现代浏览器无需 fastclick，但小厂仍用，
 大厂 H5默认：

```
html {
  touch-action: manipulation;
}
```

### ✔ Standard 8：禁止橡皮筋滚动

```
document.body.addEventListener('touchmove', (e) => {
  e.preventDefault();
}, { passive: false });
```

（大厂页面只在不需要滚动时启用，比如弹窗）
